# 垃圾处理场 · 场景简报（v1）

> 状态：2026-11-21 已实现；独立页与同页注册完成，浏览器加载、交互、碰撞、盲区与性能验收通过。`sceneId: garbage`。
> 入口：同页 `/#garbage`；独立页 `garbage/standalone.html`；`garbage/index.html` 会自动重定向到同页。
> 上级：生活区 1F，设计图集 A 区「垃圾场」的 5.4 × 5.4 m 结构开间内；门外是尚未接入的走廊（`sceneId: corridor`，锁定）。

## 1. 定位

- 名称：垃圾处理场（Refuse Yard / Garbage Processing Room）。
- 类型：学园生活区 1F 的后勤垃圾房，生活垃圾、废纸箱、旧工具和清运设备都挤在这里。
- 剧情功能：**可藏身、可翻找、被监控的垃圾房**。两台带轮工业垃圾桶是通向下方焚烧炉的投放口，负责“投放 / 封存”，门边木框和角落货架提供视线与死角；监控与显示屏挂在同一墙角，货架正好落在镜头死角。
- 氛围：暗、脏、闷；脏白墙 + 水泥地；两盏偏暗的白炽灯，一根冷白灯管接触不良地闪，另一根坏了；门缝下漏进走廊的冷光。
- 风格：自然写实骨架 + 弹丸论破式安静异常（监控红点、镜头死角、被遗弃的垃圾袋与烟味残留）。
- 禁忌：**无人物、无文字/字体贴图、无自绘二维画作、无音频、无 CDN、无网络请求**。警示牌只用“禁止吸烟”图形符号（烟 + 红圈斜杠），箱面只用三角警示图与空白标签；不出现可读字母、数字与真实品牌。

## 3. 机位

移动机位（第一人称，本场景无固定机位）：

```yaml
moving:
  enabled: true
  start: { x: 0.62, z: 2.16, yaw: 0.10, pitch: -0.035, fov: 68 }
  eyeHeight: 1.8
  playerRadius: 0.30
  speed: { walk: 2.4, run: 4.8 }
  acceleration: 16.0
  bob: { walk: 0.012, run: 0.022, frequency: 5.4, lateral: 0.45 }
  pitchLimit: 83°
  roll: 0
  substep: 0.06
  collision: true
  colliderCount: 11
```

- 动线：门口 → 垃圾桶前 → 货架前 → 西墙液体/垃圾袋堆 → 扫把/簸箕 → 木门；主通道 ≥2 m，垃圾桶与垃圾袋之间最窄约 2.0 m（玩家半径 0.30 m，余量充足）。
- 起点在门内 0.54 m，面向北偏西 5.7°；第一眼是两台垃圾桶、货架与监控角。
- 南向回望可见木门、警示牌、扫把/簸箕、垃圾袋与纸箱；门口可退到 z≈2.29，转身即可看见门缝冷光。
- 机位验收只按移动机位 gate：走遍可达区域、11 个碰撞体、冲刺 4.8 m/s 不穿透。

## 6. 灯光

```yaml
recipe: garbage.dim-tungsten
key: { type: directional, direction: down, color: "#ffd4a2", intensity: 0.92, shadow: 2048, bake: once }
fills:
  - hemisphere: 0.50（sky #c2c7ba / ground #33302a）
  - ambient: 0.15
  - 主白炽吊灯 point: 2.8（暖 #ffbb7c，5.2 m，衰减 2，光源在灯罩下 0.16 m）
  - 门边笼式裸灯 point: 1.15（#ffc78e，3.4 m）
  - 故障灯管 point: 1.1（#d8eee6，3.6 m；三频闪烁，独立回路）
  - 监控绿光 point: 0.30（#7fcb92，2.8 m）
  - 门缝冷光 point: 0.78（#c2d8d0，2.4 m）
  - 桶前低补光 0.70 / 桶顶 0.52 / 桶缘 0.22 / 垃圾袋角 0.44 / 液体反光 0.24
  - 货架补光 0.46 / 地面反弹 0.24 / 中央冷填充 0.20 / 木门 + 警示牌暖洗 0.38 / 扫把角 0.20
fixtures:
  - 绿搪瓷罩白炽吊灯
  - 门边笼式裸灯
  - 接触不良的冷白灯管（1）
  - 损坏斜挂灯管（1，不亮）
  - 监控绿屏 / 门下冷光带
postProcessing: none
exposure: 0.96
```

- 唯一投影主光垂直向下 `(0, -1, 0)`；所有补光均不投影，影子方向始终向下，不发生侧向反影。
- 主光只烘焙一次（2048² 静态阴影）；桶盖、门扇、显示屏、粒子、蛛网均不投影。
- 关灯变体：主光降到 0.24、主灯降到 0.16，保留故障灯管、监控绿光、门缝冷光与红点，仍可辨认空间。
- 所有补光都限制距离与强度，避免把脏白墙打成均匀白墙；光池集中在灯下、桶前、货架前与门缝。

## 7. 预算与验收

- 移动机位上限：≤450k 三角面 / ≤90 draw calls；目标 ≤6 万三角面 / ≤60 draw calls。
- **实测（1600 × 900，ANGLE D3D11，NVIDIA GTX 1060 3GB，软件截图模式）**：静态 **49 批 / 31,872 三角面**；hero 视角 **73 draw calls / 34,516 三角面**；全场景最高 **88 draw calls / 37,664 三角面**；**空载 60 FPS**；同机并行构建其他场景时实测 **50–56 FPS**（主机负载所致）。
- 纹理 **21 个纹理对象**、总计约 **5.4 MB**（单张 ≤512²，地板 512×640，木门/墙 256–512）；无外部请求。
- 单张 2048² 静态阴影；无后处理、无 Bloom/SSAO；无动态分辨率降级（60 FPS 稳定）。
- 碰撞：11 个碰撞体（4 墙 + 2 桶 + 货架 + 垃圾袋 + 纸箱 + 扫把/簸箕 + 门）；0.06 m 子步进；巡场 421 步 + 4 次冲撞，**穿透 0**。
- 监控死角：镜头轴到货架向量夹角 **52.4°–52.8°**，镜头半角 34°，`blind: true`。
- 交互：门锁定不切场；灯开关正常；桶盖 0 ↔ -1.65 rad 正常；无控制台错误/警告。
- 验收细则见 [VALIDATION.md](VALIDATION.md)。
