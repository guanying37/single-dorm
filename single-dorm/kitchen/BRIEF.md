# 学生餐厅后厨 · 场景简报（v2）

> 状态：2026-11-15 按本轮修改实现并通过浏览器验收。`sceneId: kitchen`。
> 入口：同页 `/#kitchen`；独立重定向页 `kitchen/index.html`。

## 1. 定位

- 名称：学生餐厅后厨（Student Dining Kitchen）。
- 类型：商用后厨 / 备餐、烹饪、清洗。
- 功能：学生餐厅的服务后台；从餐厅后厨门进入，可从后厨独立木门返回餐厅。
- 风格：现代化商用厨房，不锈钢金属色 + 冷白光 + 白色墙砖；一扇与餐厅一致的橡木门形成材质对比。
- 禁忌：**无人物、无文字、无自绘二维画作、无音频、无 CDN、无网络请求**。CRT 画面仅做抽象后厨影像。

### 门

1. **回餐厅门（新增）**：后厨东墙 z=-7，1.0 × 2.2 m，与餐厅后厨门同款橡木/磨砂玻璃/黄铜把手，铰链镜像；点击后黑屏切场回餐厅。餐厅侧对应门在餐厅东墙 z=6.3、靠正门一端。
2. **前厅出餐口**：东墙 z=+5.5，2.4 × 2.2 m 洞口 + 0.95 m 传菜台 + 双开防撞门 + 暖光交接廊。
3. **后厨专用通道/货运电梯**：西墙 z=+3.0，1.7 × 2.2 m 双扇不锈钢货梯门。
4. **冷库**：北墙 x=+4.6，1.3 × 2.2 m 厚重不锈钢门，带防凝露加热丝。

## 3. 移动机位

```yaml
moving:
  enabled: true
  start: { x: 2.4, z: 4.0, yaw: 0.32, pitch: -0.03, fov: 68 }
  eyeHeight: 1.8
  playerRadius: 0.30
  speed:
    walk: 5.2       # 旧跑步速度
    run: 11.0       # 几乎失控
  acceleration: 18.0
  bob: { walk: 0.012, run: 0.022, roll: false }
  pitchLimit: 83
  collision: true
  colliderCount: 19
```

动线：回餐厅门/出餐口 → 岛台 → 烹饪区 → 西侧挂杆/货梯 → 冷库 → 南侧清洗/售饭台。主通道 ≥1.2 m。

## 4. 交互与切场

- 餐厅 `door.kitchen`：餐厅东墙 z=6.3、靠正门一端；点击/按 E → 黑屏「前往 餐厅后厨」→ 后厨门内落点 `(4.7, -7)`，yaw 面向西、pitch 0。
- 后厨 `door.dining`：东墙 z=-7；点击/按 E → 黑屏「前往 学生餐厅」→ 餐厅新门内落点 `(16.7, 6.3)`，面向大厅（yaw π/2）、pitch 0。
- 两侧落点都在门内，切场期间锁定输入；视角回到水平朝向房间内部。
- 餐厅 `door.main`：**锁定**，不可打开；只显示「正门 · 暂未开放（预留走廊切换）」，并保留 `sceneId: 'corridor'` 钩子。

## 7. 预算与验收

- 移动机位：≤450k 三角面、≤90 draw calls；实测 **34k–39k 三角面 / 23–43 draw calls**。
- 纹理 ≤16 MB，13 张 ≤512² 程序化贴图。
- 阴影只烘焙一次；动态 CRT 不投影。
- 移动/碰撞/视角/切场测试见 [VALIDATION.md](VALIDATION.md)。
