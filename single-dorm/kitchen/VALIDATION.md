# 后厨验收记录（v2）

- 场景：`sceneId: kitchen`，学生餐厅后厨。
- 日期：2026-11-15。
- 机位：**移动机位 only**（同页宿舍为固定机位，餐厅为移动机位；三者预算分开）。
- 浏览器：Microsoft Edge 157（headless / NVIDIA GTX 1060 3GB / Direct3D11；截图 1600 × 900）。
- 运行时：本地 `python -m http.server 8123`，**无 CDN、无外部请求**。

## 9. 遗留 / 可接受边界

1. 后厨只做移动机位，不提供固定 ADV 机位。
2. 回餐厅门、出餐口双开门、冷库门、货梯门为静态闭合；回餐厅门用黑屏切场，不做开门弧线。
3. CRT 监控画面为程序化抽象影像，不可读、无文字。
4. 餐厅正门目前锁定；后续接走廊场景时把 `sceneId: 'corridor'` 的锁定改为切场。
5. 11 m/s 跑步速度按需求设置为“接近失控”，碰撞仍按 0.075 m 子步进解算；实际手感由玩家练习适应。

## 10. 复现命令

```powershell
cd single-dorm
python -m http.server 8123 --bind 127.0.0.1
# 另一个终端
node kitchen/tools/motion-test.mjs
node kitchen/tools/final-capture.mjs
```

> `tools/` 使用 Node 24 内置 `WebSocket` 与 Edge 的 DevTools Protocol；无需 npm 依赖。运行前需要 Edge 以 `--remote-debugging-port=9222` 启动并打开本地预览。
