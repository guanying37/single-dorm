# 后厨冷库储藏室 · 场景简报（v1）

> 状态：2026-11-15 实现并通过浏览器验收。`sceneId: coldstore`。
> 入口：同页 `/#coldstore`；独立重定向页 `coldstore/index.html`。
> 上级：学生餐厅后厨北墙的冷库门（`kitchen` → `coldstore` 单向进门，冷库内重门反向回后厨）。

## 1. 定位

- 名称：后厨冷库储藏室（Walk-in Cold Store）。
- 类型：餐厅后厨配套的保鲜/冷冻库房，工业仓储风，密封 + 保温。
- 剧情功能：后厨的食材取放与冷库探索点；从后厨北墙冷库门进入，从同一扇重门返回。
- 风格：不锈钢银灰 + 保温板本白；冷白 LED + 极浅的青绿 CRT 荧光；金属、霜、雾。
- 禁忌：**无人物、无文字、无自绘二维画作、无音频、无 CDN、无网络请求**。标签只有抽象色块，CRT 只有抽象库内/门外画面与两枚无刻度指针表。

## 3. 移动机位

```yaml
moving:
  enabled: true
  start: { x: 0.26, z: 2.3, yaw: 0.06, pitch: -0.02, fov: 70 }
  eyeHeight: 1.8          # 恒定，仅步伐起伏
  playerRadius: 0.30
  speed: { walk: 1.9, run: 3.9 }
  acceleration: 16.0
  bob: { walk: 0.011, run: 0.021, frequency: 5.4, lateral: 0.45 }
  pitchLimit: 83°
  roll: 0                 # 永不侧倾/倒置
  substep: 0.06
  collision: true
  colliderCount: 9
```

动线：冷库门 → 门口周转区（2.8→1.5 m）→ 1.26 m 单通道 → 通道尽头挂衣区，往返即全部可达区域。主通道净宽 1.26 m，单人搬运可转身。

## 4. 交互与切场

- 冷库内 `door.kitchen`：触摸/点击门扇或按 `E` → 黑屏「前往 餐厅后厨」→ 后厨落点在冷库门外 `(4.6, -10.15)`，面向南、pitch 0。
- 后厨 `door.coldstore`：北墙 1.3 × 2.2 m 冷库门（原模型，新增不可见拾取体）→ 黑屏「前往 冷库储藏室」→ 冷库落点在门内 `(0.26, 2.3)`，面向通道、pitch -0.02。
- 两侧切场期间锁定输入、清空按键；到达后视角回到水平朝向房间内部；场景常驻，不重新加载。

## 6. 灯光

```yaml
recipe: coldstore.led
key: { type: directional, direction: down, color: "#f1f9ff", intensity: 1.05, shadow: 1024, bake: once }
fills:
  - hemisphere: 0.34（sky #dfeef8 / ground #4b585e）
  - ambient: 0.06
  - 2 × LED 冷白 point（2.0，3.3 m）
  - 蒸发器冷蓝 point（1.1）
  - CRT 荧光绿 point（0.34 / 1.25 m）
  - 门框加热丝暖 point（0.22）
  - 门口补光（0.8）
fixtures:
  - 2 × 防潮防爆 LED 冷库灯（发光面 + 透明防尘罩 + 冷凝霜）
  - 蒸发器冷风机（出风口冷蓝光）
  - CRT 荧光屏（动态扫描 + 闪烁）
postProcessing: none
exposure: 0.85
```

- 唯一投影主光是垂直向下的定向光；吊顶不投影，光可进入房间。
- 动态物体（CRT、风扇、冷雾）不投影；阴影只烘焙一次。
- 无 Bloom / SSAO；无侧向补光造成的影子矛盾。

## 7. 预算与验收

- 移动机位上限：≤450k 三角面 / ≤90 draw calls；实测 **约 4.8 万–5.6 万三角面 / 43–70 draw calls**（随机位与可见批次变化），1600×900 约 59–60 FPS。
- 纹理：16 张程序化贴图，单张 ≤512²，无外部请求。
- 场景静态合批 40 批；只有门叶、CRT 屏幕/扫描带、2 组风扇、2 层冷雾是动态对象。
- 移动、碰撞、视角、双向切场、四场景切换测试见 [VALIDATION.md](VALIDATION.md)。
