## 6. 复用与 one-off

### 复用

- `StaticBuilder`、`CollisionWorld`、`uvScaledPlane / trs / roundedBoxGeometry / latheGeometry / tubeGeometry` 等共享几何工具（餐厅 / 后厨）。
- 第一人称控制器结构（存储 / 冷库同构）：眼高 1.80、0.30 m 圆、0.06 m 子步、零侧倾。
- 接触阴影 / 尘埃 / 程序化贴图 / 单张静态阴影的做法。

### 新增（可复用到其他场景）

- 砖墙、木板天花、木地板镶嵌、封窗木板组、实木门套、书架、书、阅读桌、靠背椅、绿罩灯、木质吊灯、软垫长凳、落地地球仪、黑色枪机、衣帽架、浅浮雕画框。
- 这些模块的尺寸和 pivot 都按米制记录，可直接用于教室、走廊、宿舍变体；封窗木板组可直接复用到其他“钉死窗户”的房间。

### one-off

- 顶点色地球仪（大陆/极地/经纬线全部程序化，无位图）；本次重做了落地立柱/宽底盘/铜托碗，修复旧版立柱建在房间原点导致的悬空。
- CRT 监控显示屏（云台 + 凸弧屏 + 扫描带 + 录像灯）。
- 两台新增黑色枪机 + 吸顶杆 + 红色录像灯。
- 整组封窗木板（每扇 6 板 + 竖压条 + 斜撑 + 钉子 + 深腔），参考单人宿舍封窗。
- 可开合木制人字梯。
- 5 幅墙面 3D 浅浮雕（地图/风景），内容与本场景的砖墙/书架尺度绑定。

## 7. 命名与约定

- 房间 / kit / 家具 / 道具前缀：`room.*`、`kit.*`、`furniture.*`、`prop.*`。
- 家具 pivot 在底部中心；门在铰链；墙在底部中心；窗在洞口中心。
- 材质槽：木、砖、金属（黄铜/铁）、布（绒/书脊布）、生木板、深腔/近黑、纸、发光体。
- 碰撞：墙 AABB、家具 OBB（当前均为 AABB）、小道具无碰撞；动态人字梯使用覆盖开合范围的静态 AABB；封窗木板与三台监控均无碰撞。
- 所有文字只存在于 UI / 文档，场景内无文字贴图；地图/风景/书脊不生成可读标签。
