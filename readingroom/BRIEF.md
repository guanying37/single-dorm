# 阅览室 · 场景简报（v2 · 封窗版）

> 状态：2026-11-21 已实现，浏览器 / 移动 / 碰撞 / 交互 / 性能验收通过。`sceneId: readingroom`。
> 入口：同页第 7 个标签「阅览室」`/#readingroom`；独立重定向页 `readingroom/index.html`。
> 上级：生活区 1F 北侧 F 位；北墙三扇窗**已用木板完全封死**，南墙门接 2.4 m 主走廊（`sceneId: corridor`，锁定）。

## 1. 定位

- 名称：阅览室（Reading Room）。
- 类型：生活区一层的公共阅览室，学生自习、翻书、查地图的地方。
- 剧情功能：日常探索与安静独处；三张长桌上可以放线索书、摊开的册子和地图，窗下长凳适合一段独白；北窗被完全封死，室内只有灯具照明，角落 CRT 与两台监控摄像持续注视着房间，比普通阅览室更封闭、更不安。
- 氛围：暖、旧、木质感。棕色木板天花与同色木地板、红砖墙、深棕实木书架、绿玻璃罩阅读灯、三盏复古工业吊灯；北墙是一整排钉死的浅色生木板，没有窗外景色，所有光都来自灯。
- 风格：自然写实骨架 + 弹丸论破式安静异常（封死的窗、角落 CRT、三处红色录像灯）。
- 禁忌：**无人物、无文字/可读标签、无自绘二维画作、无音频、无 CDN、无网络请求**。墙上的「复古地图 / 风景」是 3D 浅浮雕，不是位图；书脊没有书名；监控画面没有时间码或字幕。

### 家具布局

- **书架**：6 组 / 10 跨，总长约 12 m；每跨 1.2 m，五层书（约 1 188 本），层板前挡边、黄铜书立、少量平叠书与倾斜书。
- **阅读桌**：3 张（2.4 / 2.4 / 1.8 m 长 × 0.95 m 宽 × 0.76 m 高），长轴沿 Z，居中 x = 0；每桌两盏绿玻璃罩阅读灯（共 6 盏）、摊开的书、合起的书摞、纸与铅笔。
- **椅子**：10 把木靠背椅，4 + 4 + 2，沿桌子两侧独立摆放。
- **窗下长凳**：木框 + 深绿绒面坐垫 + 三只抱枕 + 布包扣；头顶是被木板封死的窗，凳下有一小摞书。
- **地球仪**：三条弯脚 + 宽木底盘 + 车木立柱 + 黄铜铜箍/托碗 + 子午圈；球体用顶点色画出大陆、极地与经纬线，缓慢自转。立柱、底盘与球体共用同一个 x/z，球体确实坐在托碗里（修复了旧版“悬空”的问题）。
- **衣帽架**：三条弯脚、车木立柱、四个黄铜衣帽钩、两只木衣架、黄铜环。
- **人字梯**：木框 + 4 级踏面 + 顶部小平台 + 黄铜防滑条；收在两组书架之间的 0.6 m 缺口里，可开合。
- **监控**：CRT 外壳、凸弧荧光屏、扫描带、旋钮、电源灯与录像红灯（东南角）；西北吊顶角一台、门上方一台黑色枪机，均带红色录像灯与吸顶杆。

### 与设计图的关系

- 设计图集 A-01 的 **F 阅览** 位于生活区 1F 北侧条带，标注 15.48 × 5.4 m / 83.6 ㎡。
- 本模型严格取 **5 : 8**，体量 **6.25 × 10.0 m / 62.5 ㎡**，并把北侧封窗、南门接走廊、东北角地球仪等关系保留下来；进深大于概念图的 5.4 m 条带，这是为了满足 5:8 与「几组书架 + 三张长桌 + 飘窗 + 地球仪 + 衣帽架」同时成立所做的建模取舍。
- 该差异属于**概念图与建成模型的已知偏差**，需要在下一轮 A-01 图纸更新时把 F 位改成 6.25 × 10.0 或把条带加深；本次不改设计图集，避免与同批其他场景的图纸改动冲突。

## 3. 机位

本场景为**移动机位（第一人称）**，无固定机位。原因：阅览室是日常可自由探索的房间，书架走道、桌间与角落都需要可达；固定机位会掩盖书架背面的空洞。

```yaml
moving:
  enabled: true
  start: { x: -1.45, z: 4.30, yaw: -0.08, pitch: -0.03, fov: 68 }
  eyeHeight: 1.8
  playerRadius: 0.30
  speed: { walk: 2.6, run: 5.4 }
  acceleration: 16.0
  bob: { walk: 0.013, run: 0.021, frequency: 6.2, lateral: 0.35 }
  pitchLimit: 83°
  roll: 0
  substep: 0.06
  collision: true
  colliderCount: 28
```

- **动线**：南门内 → 中央阅读桌排西侧走道 → 北墙封窗/长凳/地球仪 → 东侧走道 → 人字梯与书架缺口 → 折返 → 西南角衣帽架/门。东西走道净宽约 1.71 m（书架前脸 → 椅背），人字梯处最窄约 1.15 m，均大于 0.60 m 玩家直径。
- **起点**：门内 0.7 m，面向北略偏东，第一眼是中间一排阅读桌、三盏吊灯与一整排钉死的木板窗；转身即见门、开关、门上方监控与衣帽架。
- 桌面只挡桌板、椅子独立碰撞，玩家可以贴到桌边看桌上的书与绿灯，也可以绕到每把椅子背后。

## 6. 灯光

```yaml
recipe: readingroom.sealed-warm-pendant
key: { type: directional, direction: down, color: "#ffe6c4", intensity: 1.06, shadow: 2048, bake: once }
fills:
  - hemisphere: 1.00（sky #e8dcc4 / ground #6e5238）
  - ambient: 0.42（#ffe8cc）
  - 吊灯点光 ×3: 3.2（#ffc98c，6.8 m，位于罩口下 0.14 m）
  - 阅读灯点光 ×3: 1.8（#d8ecc0，3.3 m，桌面中心）
  - 书架走道补光 ×4: 0.72（#ffe0b4，3.6 m）
  - 门口/衣帽架补光 ×1: 0.50（#ffd9ac，2.9 m）
fixtures:
  - 木质锥罩工业吊灯 ×3
  - 绿玻璃罩阅读灯 ×6
  - 封死北窗（不发光；板缝只有极弱的冷光条）
  - 角落 CRT 屏幕与三处录像红灯
postProcessing: none
exposure: 1.16
```

- 北窗完全封死，**没有任何窗光或日光方向光**；室内照明全部来自 11 盏点光 + 垂直向下主光 + 半球/环境光。
- 唯一投影主光垂直向下；吊灯、桌灯、书架/门口补光、屏幕与红灯全部**不投影**，影子方向始终向下。
- 关灯变体：吊灯降到 0（主光保留 0.48、半球光 0.82），桌灯、书架补光、监控屏幕与红灯仍可辨；桌灯变体同理。
- 单张 2048² 静态阴影，场景稳定后不重烘焙；动态的灯泡、绿玻璃罩、开关、人字梯、地球仪、CRT、摄像红灯与粒子均不投影。
- 无 Bloom / SSAO；暖色靠光源色温与木质材质，不靠后处理。

## 7. 预算与验收

- 移动机位上限：≤450k 三角面 / ≤90 draw calls；目标 ≤10 万三角面 / ≤70 draw calls。
- **实测：静态 52 批 / 120,626 三角面；hero 视角 80 draw calls / 140,180 三角面；视角范围 42–80 draw calls / 76,572–140,180 三角面。**
- **1600 × 900 · GTX 1060 3GB · D3D11：干净环境 60 FPS（quality 1）；多场景并行截图时共享 GPU 会跌到 30–50 FPS（同环境的杂物间对照也只有 33–47 FPS），以干净环境的 60 FPS 为准。**
- 程序化贴图 15 张（单张 ≤1024²；砖墙 1024²、地板 768²、天花 512×256、封窗生木板 256²），约 14.4 MB 含 mipmap；无外部请求。
- 碰撞：28 个碰撞体，0.06 m 子步进，0.30 m 玩家半径，全部测试 0 穿透。
- 验收明细见 [VALIDATION.md](VALIDATION.md)。

## 9. 已知边界 / 未完成项

- 无固定机位：本场景按移动机位设计与验收；如果剧情需要固定 ADV 镜头，应在 `cameraModes.fixed` 另补 3–5 个 shot 并单独验收，不复用移动机位标准。
- 门锁定，走廊不进入；`sceneId: corridor` 已预留。
- 设计图 A-01 的 F 条带（15.48 × 5.4）与建成体量（6.25 × 10）存在已知偏差，见 §2；下一轮图纸更新时统一。
- 北窗完全封死，没有窗外景色、没有日光；如果之后剧情需要“打开/拆掉一两块木板”的变体，应作为交互另做（当前木板是静态合并几何）。
- 书是盒体 + 书脊布 + 书口纸页，没有可读书名；地图/风景为 3D 浅浮雕，没有文字。
- CRT 是程序化抽象监控画面（无人物、无时间码），不是实时渲染目标；两台枪机是静态模型，红灯共用材质呼吸，不做真实云台扫视。
- 地球仪已从旧版的悬空修复为落地立柱 + 托碗 + 三弯脚；球体仍缓慢自转，不做手动旋转交互。
- 关灯变体只切换灯光，不改变时间/窗外（已无窗）。
