# 杂物间 · 场景简报（v1）

> 状态：2026-11-20 已实现，浏览器与移动/交互/百叶验收通过。`sceneId: storage`。
> 入口：同页 `/#storage`；独立重定向页 `storage/index.html`。
> 上级：生活区 1F，餐厅 / 后厨 / 冷库同一套后勤空间；门外是尚未接入的走廊（`sceneId: corridor`，锁定）。

## 1. 定位

- 名称：杂物间（Storage Room / Janitor's Store）。
- 类型：教学与生活区共用的旧储物间，清洁工具、旧货、修理工具与废弃衣物都堆在这里。
- 剧情功能：**可藏身、可窥视的旧储物间**。门上的百叶通风口是单向视线——站在里面能看见外面的走廊，外面看不见里面。监控在东北角俯视整条通道。
- 氛围：旧、暗、冷、尘土；毛坯混凝土墙与地；一盏昏黄裸灯；门外走廊的冷白荧光从百叶缝隙漏进来。
- 风格：自然写实骨架 + 弹丸论破式安静异常（监控红点、单向百叶、被遗弃的衣物）。
- 禁忌：**无人物、无文字、无自绘二维画作、无音频、无 CDN、无网络请求**。纸箱/罐子/报纸只有抽象色块和折痕，禁止可读字母、数字与真实品牌。

## 3. 机位

移动机位（第一人称，本场景无固定机位）：

```yaml
moving:
  enabled: true
  start: { x: 0.30, z: 1.90, yaw: 0.03, pitch: -0.02, fov: 68 }
  eyeHeight: 1.8
  playerRadius: 0.30
  speed: { walk: 2.0, run: 4.2 }
  acceleration: 15.0
  bob: { walk: 0.012, run: 0.022, frequency: 5.6, lateral: 0.45 }
  pitchLimit: 83°
  roll: 0
  substep: 0.06
  collision: true
  colliderCount: 10
```

- 动线：门口 → 货架前 1.84 m 主通道 → 北端麻袋/地毯角 → 折返；东侧杂物前最窄约 1.2 m，玩家半径 0.30 m，净宽足够。
- 起点面向室内（yaw 0.03，基本朝北），第一眼是货架与吊灯；转身即可看到百叶门与门缝光。
- 门口可站到 z≈2.01、x≈0.30，眼高 1.80 m，略低头即可从百叶看到走廊地面与对面墙。

## 4. 交互

| id | 类型 | 行为 |
| --- | --- | --- |
| `door.storage` | 锁定门 | 提示「杂物间门 · 暂未开放（预留走廊切换）」，不切场；挂牌 `sceneId: corridor` |
| `toolbox` | 开合 | 打开/合上修理工具箱盖（墙侧铰链，盖开 1.62 rad）；托盘随盖抬升 0.075 m，露出螺丝刀/锤子/扳手/卷尺；动态物体不投影 |
| `light.switch` | 开关 | 顶灯开/关；关灯后仍有百叶冷光、监控红点与走廊溢光，不出现死黑 |

## 6. 灯光

```yaml
recipe: storage.dim-bulb
key: { type: directional, direction: down, color: "#ffdfb0", intensity: 0.58, shadow: 1024, bake: once }
fills:
  - hemisphere: 0.40（sky #c9d0c8 / ground #3a3733）
  - ambient: 0.12
  - 裸灯 point: 2.3（暖 #ffc98c，4.6 m，衰减 2，光源下移到灯罩下方 0.22 m）
  - 百叶外冷光 point: 0.75（#d6e6ec，2.2 m）
  - 走廊顶灯 point: 1.8（#e6f0ec，3.5 m）
  - 走廊笼式壁灯 point: 1.0（#e4eef2，2.3 m）
  - 门口补光 0.52 / 地面反弹 0.18 / 衣物与工具箱补光 0.34 / 尽头反弹 0.30
  - 监控红点：自发光 + 红点 Sprite，不投影
fixtures:
  - 裸灯泡 + 搪瓷灯罩
  - 百叶通风口（唯一外光入口）
  - 走廊顶灯 + 笼式壁灯
  - 监控红点
postProcessing: none
exposure: 0.9
```

- 唯一投影主光垂直向下；裸灯与走廊光均为非投影填充，影子方向始终向下。
- 百叶光带用地面加法贴片表现（叶片遮挡的条纹 + 落点衰减），不另开投影灯。
- 关灯变体：主光降到 0.18、裸灯降到 0，保留百叶/走廊光与红点，仍可辨认空间。

## 7. 预算与验收

- 移动机位上限：≤450k 三角面 / ≤90 draw calls；目标 ≤6 万三角面 / ≤60 draw calls。
- **实测：静态 50 批 / 30,724 三角面；hero 视角 74 draw calls / 32,212 三角面；GTX 1060 · 1600×900 稳定 60 FPS。**
- 纹理 ≤16 MB，单张 ≤512²（地板 512×1024），共 19 张程序化贴图；无外部请求。
- 单张 1024² 静态阴影；动态门/工具箱盖与托盘/摄像/粒子不投影。
- 百叶探针：室内 16/21 条看穿，走廊 0/21 条看入；见 [VALIDATION.md](VALIDATION.md)。
- 验收：移动/碰撞/视角/开关灯/工具箱/百叶视线/五场景切换/性能，见 [VALIDATION.md](VALIDATION.md)。
