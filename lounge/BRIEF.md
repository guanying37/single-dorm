# 生活区二层休息厅 · 场景简报（v1）

> `sceneId`: `scene.lounge` · 场景目录 `single-dorm/lounge/`
> 机位：**移动机位（第一人称探索）**；无固定机位，验收截图使用预设机位。
> 依据：用户任务描述 + `skills/danganronpa-adv-3d` 生产线（art-direction / modular-kit / furniture-and-props / lighting-recipes / camera-moving / performance / validation）。

## 1. 定位

- **生活区二层**的公共休息厅：宿舍区与学生宿管处之间的大厅，学生下课后打牌、下棋、聊天的地方。
- 剧情功能：日常对话、自由探索、审判前的情报交换；三扇门分别接楼梯厅（大门）、男生宿管处、女生宿管处。
- 气氛：白色墙裙 + 木饰面 + 紫红地毯 + 水晶灯，**体面但不过分奢华**；吊扇/监控/刷卡机把“被管理”的异常感压在正常陈设下面。
- 禁忌：无人物、无文字/字体贴图、无音频、无外部请求；木雕与浅浮雕只用程序化三维几何，不画二维插画。

## 5. 机位

### 移动机位（主）

- `start`: `x=-10.6, z=0.7, yaw=-87.5°, pitch=-1.2°`，眼高 1.80 m，玩家半径 0.30 m。
- 动线：大门 → 中央圆桌四周（椅背外圈）→ 南北沙发带 → 东端挂钟/沙发 → 两台宿管检测机；走廊净宽 ≥0.70 m（实测椅背到沙发前沿 0.83 m）。
- 相机：FOV 68、俯仰 ±83°、无侧滚；走路/跑步起伏与餐厅一致。
- 碰撞：墙、门扇（动态）、圆桌（圆形）、14 把椅子（独立 OBB）、19 组沙发、16 个条案、门外边柜。

## 8. 灯光

```yaml
recipe: lounge.chandelier
key:
  type: directional
  direction: down      # 唯一投影主光，垂直向下
  color: "#fff2df"
  intensity: 0.72
fixtures:
  - chandelier.crystal ×5   # 非投影聚光，白光 4000K
  - fan.warm ×2             # 非投影点光，暖黄 2700K
  - landing.sconce          # 门外暖光，非投影
ambient:
  hemisphere: 0.42
  ambient: 0.15
shadow:
  map: 2048²
  bakedOnce: true
```

- 阴影只由垂直向下主光产生；吊灯聚光、吊扇暖光、门外灯全部 `castShadow=false`。
- 吊灯灯泡与水晶、检测机灯、监控红灯用 emissive；无 Bloom/SSAO。
- ACESFilmic，曝光 1.02。

## 10. 验收

- 空间：墙/地/顶无黑洞，三扇门与门外预留段完整；进门可看到圆桌与吊灯，走到东南西北均有陈设。
- 家具：Ø5 m 桌、14 椅、19 沙发、16 条案、15+3 件木雕、5 吊灯、2 吊扇 + 2 监控、4 空调、1 挂钟、2 检测机。
- 移动：0.30 m 玩家半径跑动不穿墙/桌/椅/沙发；门扇动态碰撞同步。
- 光影：唯一投影主光垂直向下，高物体影子在脚下；无侧向 key。
- 性能与 console 无 error、无 404、无外部请求。
- 截图：入口、桌面、大门、检测机、沙发带、天花、挂钟 7 张以上。
