# 医务室 · 场景简报（v1.1 实现版）

> `sceneId: infirmary` · 同页入口 `/#infirmary` · 独立入口 `infirmary/`（自动跳转）
> 状态：2026-11-21 已实现；浏览器加载、交互、碰撞与切换验收通过。
> 上级空间：生活区 1F，餐厅 / 后厨 / 冷库 / 杂物间同一套后勤与生活空间。

## 1. 定位

- 名称：医务室（Infirmary / School Clinic）。
- 类型：希望峰学园生活区的日常诊疗室，兼作小型处置/手术空间。
- 剧情功能：体检、包扎、隔离观察、术后恢复；五张可移动病床与可开合隔帘让这里也能成为“谁都能听见帘子后面动静”的封闭空间。
- 氛围：白、亮、干净、略带无菌感；浅蓝隔帘与防撞扶手是唯一的冷色大块面，绿萝和浅橡木药柜把空间从“医院”拉回“学校”。
- 风格：自然写实骨架 + 弹丸论破式安静异常（高处监控与显示屏、无影灯、黄红医疗废弃物桶、门上的绿色十字）。
- 禁忌：**无人物、无文字、无自绘二维画作、无音频、无 CDN、无网络请求**。药瓶标签、抽屉标签、显示屏画面只使用抽象色条与图形，不出现可读文字/数字。

## 3. 机位

本场景为**移动机位**（第一人称），无固定机位。

```yaml
moving:
  enabled: true
  start: { x: 1.15, z: 3.48, yaw: 0.0, pitch: -0.02, fov: 68 }
  eyeHeight: 1.8
  playerRadius: 0.3
  speed: { walk: 2.2, run: 4.4 }
  acceleration: 15.0
  bob: { walk: 0.012, run: 0.022, frequency: 5.6, lateral: 0.45 }
  pitchLimit: 83°
  roll: 0
  substep: 0.06
  collision: true
  colliderCount: 22
```

- 动线：门内 → 洗手池/药柜前 → 中央过道 → 手术台旁 → 五床尽端 → 折返。
- 主过道净宽：床尾 x=-0.51 到药柜前 x=+2.09，约 2.6 m；手术台东侧 x=+1.27 到墙/柜前 1.0–1.2 m；床间净距 0.63 m，0.30 m 玩家半径可进入。
- 起点正对五床与手术台，第一眼看到蓝色隔帘、白色被铺与无影灯；右转是洗手池/镜子/药柜，左转是五床和床间小推车。

## 4. 交互

| id | 类型 | 行为 |
| --- | --- | --- |
| `door.infirmary` | 锁定门 | 提示「医务室门 · 暂未开放（预留走廊切换）」，不切场；挂牌 `sceneId: corridor` |
| `curtain.1` … `curtain.5` | 开合 | 每道双片帘：打开时两片收拢到床尾过道一侧（scale.x 0.5），关闭时在中线合拢（scale.x 1）；软帘不设碰撞体，避免把玩家夹在床与帘之间 |
| `cabinet.glass` | 横拉 | 西侧玻璃门滑到东侧玻璃门后，露出左半柜；关闭时两片在中线对接 |
| `cabinet.drawer.1/2/3` | 拉出 | 三层浅橡木抽屉各向外拉出 0.30 m，露出白色/蓝色长方体包装；关闭时回到柜体 |
| `waste.bin` | 开盖 | 红色桶盖沿北侧铰链抬起 1.15 rad，露出红色医疗废弃物袋 |

- 门锁定，不切场；后续接入走廊时只替换 `sceneId` 与隐藏门外切片即可。
- 交互距离 3.9 m；点击或 `E` 均可触发；所有动态件不投影，静态阴影只烘焙一次。

## 6. 灯光

```yaml
recipe: infirmary.daylight-clinic
key: { type: directional, direction: down, color: "#fff7ea", intensity: 1.75, shadow: 2048, bake: once }
fills:
  - hemisphere: 0.42（sky #e7f1f4 / ground #9aa5a0）
  - ambient: 0.12
  - ceiling.panel ×3 point: 1.45（#f1f8ff，5.2 m，decay 2）
  - surgical.point: 2.8（#fff2dc，3.4 m）
  - cabinet.point: 0.9（#fff7e8，1.5 m，玻璃柜内）
  - basin.point: 0.7（#eaf5f8，2.6 m）
  - north.bounce: 0.5（#f2f7ee，3.0 m）
fixtures:
  - 6 × LED 平板灯（5000–6000K）
  - 无影灯（6 透镜 + 淡金光晕）
  - 玻璃柜内暖白灯
  - 监控红点 / 显示屏录制点
postProcessing: none
exposure: 0.96
```

- 唯一投影主光垂直向下；所有灯具只做非投影填充，影子方向始终向下。
- 无影灯使用 6 个自发光透镜 + 淡金色 additive 光晕，不做 Bloom。
- 镜面使用一次性 128 px cube map，避免运行时第二相机。

## 7. 预算与验收

- 移动机位上限：≤450k 三角面 / ≤90 draw calls；本场景目标 ≤140k / ≤80。
- **实测（standalone 1600×900 · headless Edge/SwiftShader）**：静态 36 批 / 106,342 三角面；hero 视野 **70 draw calls / 116,734 三角面 / 60 FPS**；各机位 23–70 draw calls。
- 14 张程序化贴图，单张 ≤1024²；无后处理；一张 2048² 静态阴影；所有动态件不投影。
- 碰撞：22 个静态碰撞体、0.30 m 玩家半径、0.06 m 子步进；跑动测试 0 穿透（见 `VALIDATION.md`、`preview/motion-report.json`）。
- 交互：11 个交互体（门、5 帘、玻璃门、3 抽屉、垃圾桶盖），全部有状态与动画。
- 渲染器：ACESFilmic，曝光 0.96；无 Bloom/SSAO；单场景 60 FPS。
