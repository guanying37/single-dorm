# 场景验收清单

## 简报

- [ ] sceneId/名称/地点类型/剧情功能
- [ ] 尺寸/层高/门洞/连接
- [ ] mode
- [ ] 3–5 个相机锚点
- [ ] 交互 id/行为
- [ ] reuse/new/oneoff 资产
- [ ] 灯光配方/阴影方向
- [ ] 预算/禁忌

## 资产

- [ ] 尺寸/pivot/材质槽/碰撞
- [ ] 复用场景
- [ ] 无文字小道具
- [ ] 植物有枝干/叶柄
- [ ] 墙面道具不重叠/不穿门窗

## 空间

- [ ] 门口可进入
- [ ] 门洞净宽 ≥0.70 m
- [ ] 主通道不堵
- [ ] 墙地顶无缝隙/黑洞
- [ ] 机位无穿帮

## 相机

- [ ] 3–5 个机位
- [ ] 构图有差异
- [ ] 不穿墙/家具
- [ ] 可走/机位切换正常

## 碰撞

- [ ] 墙不可穿
- [ ] 桌面/椅子独立碰撞
- [ ] 桌角可走近
- [ ] 动态门/抽屉碰撞同步
- [ ] 不卡死

## 光影

- [ ] 一个投影主光
- [ ] 顶灯室内垂直向下
- [ ] 窗光不投影
- [ ] 影子在脚下
- [ ] 无 Bloom/SSAO

## 性能

- [ ] 1080p 约 60 FPS
- [ ] 可走 ≤450k/≤90；纯机位 ≤250k/≤60
- [ ] 纹理 ≤16 MB
- [ ] 合批/静态阴影
- [ ] 无 console error/404

## 接入

- [ ] 注册表条目
- [ ] 同页切换
- [ ] 保存/恢复视角
- [ ] 本地服务器/file:// 提示
