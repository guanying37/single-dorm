# 场景验收清单

## 简报

- [ ] sceneId/名称/地点类型/剧情功能
- [ ] 尺寸/层高/门洞/连接
- [ ] 机位：固定 / 移动 / 两者都要
- [ ] 固定 shot：position/target/fov/用途
- [ ] 移动：start/眼高/半径/动线/碰撞
- [ ] 交互 id/行为
- [ ] reuse/new/oneoff 资产
- [ ] 灯光配方/阴影方向
- [ ] 固定/移动预算
- [ ] 禁忌

## 资产

- [ ] 尺寸/pivot/材质槽/碰撞
- [ ] 复用场景
- [ ] 无文字小道具
- [ ] 植物有枝干/叶柄
- [ ] 墙面道具不重叠/不穿门窗

## 空间

- [ ] 墙地顶无缝隙/黑洞
- [ ] 固定 shot 无穿帮
- [ ] 移动可达区域无黑洞
- [ ] 门洞 ≥0.70 m（仅移动）
- [ ] 主通道不堵（仅移动）
- [ ] 楼梯/高差有坡道/台阶

## 固定机位

- [ ] 3–5 个 shot
- [ ] 构图有差异
- [ ] 不穿墙/家具
- [ ] 前景/中景/背景
- [ ] 镜头切换正常
- [ ] 不要求碰撞/完整空间

## 移动机位

- [ ] start 不在墙/家具里
- [ ] 1.80 m 眼高/俯仰限制
- [ ] 走路/跑步晃动/归位
- [ ] 全屏/窗口/右键/中键
- [ ] 墙/桌/椅/门/柜/抽屉碰撞
- [ ] 快速移动不穿模/不卡死
- [ ] 可达区域无死黑

## 光影

- [ ] 一个投影主光
- [ ] 顶灯室内垂直向下
- [ ] 窗光不投影
- [ ] 影子在脚下
- [ ] 无 Bloom/SSAO

## 性能

- [ ] 固定 ≤250k/≤60
- [ ] 移动 ≤450k/≤90
- [ ] 纹理 ≤16 MB
- [ ] 合批/静态阴影
- [ ] 无 console error/404

## 接入

- [ ] 注册表条目 + modes
- [ ] fixed/moving 独立配置
- [ ] 同页切换
- [ ] 保存/恢复视角
- [ ] 本地服务器/file:// 提示
