# 建模提示词交接

> 这不是建模提示词本身。当前阶段只准备交接包；最终提示词在下一阶段再写。

## 交接包

- [ ] `scene-brief.md` 已填完
- [ ] `scene-spec.yaml` 已填完
- [ ] `asset-list.md` 已填完
- [ ] kit 模块清单
- [ ] 相机锚点
- [ ] 材质/灯光配方
- [ ] 预算
- [ ] 参考图/色板
- [ ] 未完成项

## 下一阶段提示词必须包含

1. **场景身份**：sceneId、地点、剧情功能、情绪。
2. **空间**：尺寸、层高、门洞、窗、连接房间、玩家起点。
3. **模式**：walk/fixed/hybrid；相机锚点列表。
4. **资产**：reuse/new/oneoff；每件尺寸、pivot、材质槽、碰撞。
5. **材质/灯光**：材质族、灯光配方、阴影方向。
6. **风格**：art-direction 的色板/造型/磨损规则。
7. **禁忌**：无人物、无文字、无音频、无自绘二维画。
8. **预算**：三角面/draw calls/纹理/FPS。
9. **验收**：validation.md 的 gate。
10. **输出格式**：场景模块、spec、资产清单、截图、性能数据。

## 禁止

- 不要在提示词里写“随便发挥”。
- 不要把当前餐厅的所有数字复制过去。
- 不要只给一张参考图，不给尺寸/机位/交互。
- 不要让下一阶段猜门在哪、镜头看哪、用什么灯。
- 不要在未确认简报前生成几何。
