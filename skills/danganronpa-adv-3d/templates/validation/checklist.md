# 验收清单（可打印）

## 启动

- [ ] `start-preview.cmd` 或 `python serve.py` 启动成功。
- [ ] 自动打开 `/#dining`。
- [ ] 端口被占用时打开已有预览，不报错退出。
- [ ] 直接双击 `index.html` 显示“需要通过本地服务器打开”。

## 路由

- [ ] `/` 显示宿舍。
- [ ] `/#dining` 显示餐厅。
- [ ] `/dining/` 跳转 `/#dining`。
- [ ] 顶部切换不刷新页面。
- [ ] 切换后视角保持，按键不残留。

## 内容

- [ ] 10 桌 × 6 椅 × 5 件餐具。
- [ ] 每桌花瓶 + 3–5 枝花。
- [ ] 8 幅食物画。
- [ ] 复古摆钟 + 天鹅时钟。
- [ ] 3 台空调、10 组 LED、6 台监控。
- [ ] 3 扇门；正门后无第二道门。
- [ ] 西墙餐具柜 2 门 + 3 抽屉。
- [ ] 东西墙各 1 只扬声器。
- [ ] 8 盆绿植，叶片有枝干/叶柄连接。

## 操作

- [ ] WASD 移动；Shift 加速。
- [ ] 1.80 m 眼高；跑步晃动明显更强。
- [ ] 左键拖动；全屏指针锁定；右键固定；中键回正。
- [ ] 俯仰限制；无翻转；yaw 360°。
- [ ] 页面按钮全屏；F11 可用。
- [ ] 非全屏 FPS 可见；全屏隐藏。

## 碰撞

- [ ] 墙体不可穿。
- [ ] 桌面不可穿。
- [ ] 6 把椅子各自阻挡。
- [ ] 桌角 `(1.35, 4.7)` 可站。
- [ ] 椅心 `(0.45, 4.35)` 会把玩家推到椅外。
- [ ] 开门/拉抽屉时碰撞同步。
- [ ] 快速跑动不穿模；墙角不卡死。

## 交互

- [ ] 准星/鼠标出现提示。
- [ ] 正门开/关。
- [ ] 服务门锁定提示。
- [ ] 餐具柜门/抽屉。
- [ ] 时钟 API。

## 视觉

- [ ] 所有投影主光垂直向下。
- [ ] 高物体影子在脚下。
- [ ] 宿舍只有吊灯主光；无 windowSpill/侧向 fill。
- [ ] 无门后套门。
- [ ] 无漂浮叶片/花头/餐具。
- [ ] 无穿模、接缝、黑洞。
