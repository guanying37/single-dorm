# 固定机位（ADV / 过场）

固定机位是**作者构图**，不是玩家自由观察。镜头、站位、光线、可见几何都为这一张画面服务。

## 1. 适用

- 对话、独白、审判前、回忆、过场。
- 玩家不能走动，或走动被限制在镜头之间的切换。
- 场景只需要支持 1–5 个镜头；镜头外可以不存在。
- 典型：裁判场、审讯室、剧情小房间、回忆场景。

不适用：自由探索、需要玩家绕桌子/穿门的场景。那种用 `camera-moving.md`。

## 2. 核心原则

1. **镜头先行**：先定画面，再定几何。
2. **只建镜头可见的面**：镜头外的墙、家具、天花可以省略；但不能从当前镜头看到黑洞。
3. **不要求完整可行走空间**：固定机位场景可以没有 playerStart、collision、完整门洞。
4. **不复制模型**：如果同一房间也要可走，仍然只建一份模型；固定机位只是相机预设。
5. **构图服务叙事**：前景/中景/背景、视线方向、留白、压迫感/安全感。

## 3. 镜头规格

每个固定机位必须写：

```yaml
id: shot.teacher
purpose: "上课/俯视学生席"
position: [0, 1.65, -2.7]     # 相机位置
target: [0, 1.0, 2.0]         # 看向点
fov: 55
roll: 0
height: 1.65
near: 0.05
far: 40
composition:
  foreground: "讲台边缘/粉笔槽"
  midground: "学生课桌阵列"
  background: "窗与走廊门"
lightState: "afternoon"
transition: "从 door 镜头切到 teacher 镜头"
```

### 常用镜头

| 类型 | 高度 | FOV | 用途 |
|---|---:|---:|---|
| 对话中景 | 1.45–1.65 | 45–55 | 两人对话/日常 |
| 讲台俯视 | 1.6–1.75 | 50–60 | 教室/审判 |
| 低角度压迫 | 0.8–1.2 | 40–50 | 紧张/异常 |
| 高角度俯视 | 2.0–2.6 | 45–55 | 全景/孤立感 |
| 特写道具 | 1.0–1.5 | 30–40 | 线索/桌面 |

- 相机不要穿墙；近裁剪面 0.05。
- 目标点决定构图，不要只给 yaw/pitch。
- 3–5 个镜头，不要全在同一高度/角度。
- 镜头之间要有明确切换关系。

## 4. 几何范围

- 只建镜头能看到的面；镜头外可省略。
- 门后/窗外不能是黑洞：用遮挡板、天空、雾、暗部。
- 如果同一场景也要可走，按 `camera-moving.md` 补完整空间；固定镜头仍从同一模型取。
- 固定镜头的桌面小物可以更精细；镜头外的小物可合并/省略。

## 5. 灯光

- 顶灯室内主光垂直向下；窗光/日光只做非投影填充。
- 可以按镜头切换灯光状态（白天/黄昏/停电），但主光方向不变。
- 镜头内不要出现侧向 key 造成的矛盾影子。
- 高对比镜头用暗环境 + 垂直顶光，不用侧向彩色光。
- 动态门/抽屉不投影。

## 6. 性能

| 项 | 目标 |
|---|---|
| 三角面 | ≤250k |
| draw calls | ≤60 |
| 纹理 | ≤16 MB |
| 阴影 | 1 张，1024–2048² |
| 目标 | 1080p 约 60 FPS |

- 固定机位允许更高精度的 hero prop；镜头外可 LOD/省略。
- 不需要为不可达区域做碰撞。
- 如果同场景也支持移动，按移动预算（≤450k/≤90）执行。

## 7. 验收

- [ ] 每个镜头有 position/target/fov/用途。
- [ ] 镜头内无穿模、无黑洞、无漂浮物。
- [ ] 前景/中景/背景成立。
- [ ] 镜头外不可见区域可以不存在，但不能被看到。
- [ ] 灯光方向一致；无侧向影子。
- [ ] 无人物/文字/音频/自绘二维画。
- [ ] 镜头切换不闪白、不重置场景。
- [ ] 如果同场景可走，移动端的碰撞/通道另按 `camera-moving.md` 验收。

## 8. 不要做

- 不要用固定机位标准去验收可走场景。
- 不要为每个镜头复制一套房间。
- 不要为了构图把可见的墙/门删掉后留下黑洞。
- 不要在镜头外堆不可见的 50 万面。
- 不要用侧向光“打轮廓”，破坏影子方向。
- 不要在画面里放可读文字或角色模型（角色由游戏运行时处理）。
