# 示例：单人宿舍

> 这是 reference case，不是新场景的硬规则。宿舍不展开完整建模清单；只展示“第二场景如何接入 + 灯光约束如何落地”。

## 定位

- 单人宿舍，作为餐厅之外的第二场景，与餐厅同页切换。
- 可走/环顾；保留现有宿舍模型与交互。
- 黄色花纹墙纸、白色床品、红色门厅地毯、封死的窗、衣橱/抽屉。

## 接入

- 同页顶部切换；`/` 默认宿舍，`/#dining` 餐厅。
- 场景模块暴露：`scene`、`cameraHome` 或 `start`、`interactiveMeshes`、`update()`。
- 切换保存/恢复视角，清空按键。
- 独立页只作 fallback，不作唯一入口。

## 灯光

- 宿舍只有吊灯主光。
- 删除 windowSpill 与侧向 fill。
- 垂直向下的定向光作为吊灯投影代理；吊灯点光非投影。
- 其他灯具不投影。

## 碰撞/交互

- 衣柜门/抽屉可交互，动态碰撞。
- 玩家半径 0.30 m；不能穿床/柜/墙。
- 相机固定视点或可走按场景模式。

## 不当作规则

- 宿舍的具体家具清单不进入通用 skill。
- 黄色墙纸/红色地毯是当前场景风格，不是所有宿舍变体的强制配色。
- 宿舍的相机高度/视角不作为教室/走廊默认。
