# 场景与资产验收

验收对象不是“代码看起来对”，而是：**简报完整、资产可复用、空间成立、相机成立、光影一致、性能达标、能接入**。

## 1. 简报 gate

- [ ] `sceneId`、名称、地点类型、剧情功能明确。
- [ ] 尺寸、层高、门洞、连接房间明确。
- [ ] mode（walk/fixed/hybrid）明确。
- [ ] 3–5 个相机锚点，含位置/yaw/pitch/fov/用途。
- [ ] 交互物有 id/类型/行为。
- [ ] 资产分 reuse/new/oneoff，新增有理由。
- [ ] 灯光配方明确，阴影方向明确。
- [ ] 预算明确。
- [ ] 禁忌（人物/文字/剧情）明确。

## 2. 资产 gate

- [ ] 每件新资产有真实尺寸、pivot、材质槽、碰撞。
- [ ] 家具族/道具族命名符合规范。
- [ ] 至少一个复用场景；oneoff 有说明。
- [ ] 桌面小物无碰撞、无文字。
- [ ] 植物有枝干/叶柄，不漂浮。
- [ ] 墙面道具不重叠、不穿门洞/窗/灯。
- [ ] 资产清单完整（reuse/new/oneoff）。

## 3. 空间 gate

- [ ] 房间能从门口走进去，不穿墙。
- [ ] 门洞净宽 ≥0.70 m（玩家半径 0.30 m）。
- [ ] 桌椅/柜体不挡主通道。
- [ ] 墙/地/顶无缝隙、漏面、黑洞。
- [ ] 门窗/线脚接缝自然。
- [ ] 从每个相机锚点看，无穿帮/穿模。

## 4. 相机 gate

- [ ] 3–5 个机位，构图有差异。
- [ ] 机位不穿墙/家具，y 在 1.4–1.8 m。
- [ ] 可走模式能回到玩家位置。
- [ ] ADV 机位切换不闪白/不重置场景。
- [ ] 机位不是第二套模型。

## 5. 碰撞 gate

- [ ] 墙体不可穿。
- [ ] 桌面不可穿；椅子独立碰撞。
- [ ] 桌角可走近，椅子仍阻挡。
- [ ] 柜/门/抽屉动态碰撞同步。
- [ ] 快速移动不穿模。
- [ ] 墙角/桌角不卡死。

## 6. 光影 gate

- [ ] 只有一个投影主光。
- [ ] 顶灯室内主光垂直向下。
- [ ] 窗光/日光不投影。
- [ ] 高物体影子在脚下，不侧偏。
- [ ] 动态门/抽屉不投影。
- [ ] 无 Bloom/SSAO；无纯黑阴影/过曝白墙。

## 7. 性能 gate

- [ ] 1080p 稳定接近 60 FPS。
- [ ] 可走 ≤450k 三角面 / ≤90 draw calls；纯机位 ≤250k / ≤60。
- [ ] 纹理 ≤16 MB；单图 ≤1024²。
- [ ] 静态几何合批；无每帧 geometry。
- [ ] 阴影只烘焙一次。
- [ ] console 无 error；无 404；无外部请求。

## 8. 接入 gate

- [ ] 注册表有 `sceneId`、标题、加载器、模式。
- [ ] 同页切换只渲染 active。
- [ ] 切换保存/恢复视角、清按键、重置 frozen。
- [ ] 本地服务器可启动；`file://` 有提示。
- [ ] 独立预览页可用，但不是唯一入口。

## 9. 截图

每个场景至少：

1. 总览（带 HUD/场景切换）。
2. 入口视角。
3. 主相机锚点。
4. 近景（家具/道具/材质）。
5. 灯光/阴影验证。
6. 碰撞/通道验证（可选俯视）。
7. 性能数据截图（可选）。

## 10. 交接给建模提示词阶段

交接包：

- `scene-brief.md`；
- `scene-spec.yaml`；
- `asset-list.md`；
- kit 模块清单；
- 相机锚点；
- 材质/灯光配方；
- 预算；
- 参考图/色板；
- 未完成项。

要求：下一阶段不需要再问“多大、门在哪、镜头看哪、用什么灯”。
