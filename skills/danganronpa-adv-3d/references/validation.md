# 验收、测试与截图

本文件定义“做完”的证据。没有实测数据，不要写“已通过”。

## 1. 验收顺序

1. **静态检查**：文件存在、import 路径、frontmatter、无 404。
2. **启动**：本地服务器、默认页、路由、`file://` 提示。
3. **功能**：移动、视角、交互、场景切换。
4. **碰撞**：墙、桌、椅、门、抽屉、桌角。
5. **视觉**：影子方向、穿模、接缝、漂浮、门后套门。
6. **性能**：FPS、draw calls、三角面、纹理。
7. **截图与记录**。

## 3. 路由与本地预览

- [ ] `/` 打开宿舍，页面标题/场景名正确。
- [ ] `/#dining` 直接餐厅。
- [ ] `/dining/` 跳转 `/#dining`。
- [ ] `/#dorm` 回到宿舍。
- [ ] 顶部切换不刷新页面。
- [ ] 端口占用时 `serve.py` 打开已有预览。
- [ ] `file://` 打开显示明确提示，不白屏。
- [ ] 页面无 404、无外部网络请求。

## 4. 操作

### 4.1 基础

- [ ] W/A/S/D 四向移动正确。
- [ ] 斜向不加速。
- [ ] Shift 进入跑步；松开回步行。
- [ ] 眼高基准 1.80 m。
- [ ] 走路有轻微起伏；跑步明显更强。
- [ ] 停止 0.25 s 内归位。
- [ ] 鼠标左键拖动环顾（非全屏）。
- [ ] 全屏指针锁定，光标隐藏。
- [ ] 右键固定/解锁。
- [ ] 中键回正。
- [ ] 俯仰限制 ±83°，无翻转。
- [ ] yaw 360° 无上限。

### 4.2 全屏

- [ ] 页面按钮进入 Fullscreen API 全屏。
- [ ] F11 或浏览器原生全屏可用（按项目要求）。
- [ ] 全屏隐藏 HUD/FPS/场景切换。
- [ ] 退出后 HUD/FPS 恢复。
- [ ] 全屏下鼠标锁定失败时有拖动 fallback。

## 5. 碰撞

### 5.1 墙/门

- [ ] 四面墙不可穿。
- [ ] 正门开/关时碰撞同步。
- [ ] 后厨/卫生间门锁定，玩家不能穿。
- [ ] 走廊端柜不可穿。
- [ ] 门框/门套不卡玩家。

### 5.2 桌/椅

以 `(0, 3.4)` 桌为例：

- [ ] 桌面不可穿。
- [ ] 6 把椅子不可穿。
- [ ] 空角 `(1.35, 4.7)` 可站。
- [ ] 椅子中心 `(0.45, 4.35)` 会把玩家推到约 `z=4.94`。
- [ ] 不能从桌下穿过。

### 5.3 动态

- [ ] 餐具柜门开/关时碰撞同步。
- [ ] 抽屉拉出/收回时碰撞同步。
- [ ] 快速跑动不穿模。
- [ ] 贴墙滑动不抖动。
- [ ] 墙角/桌角不卡死。

## 6. 交互

- [ ] 准星/鼠标命中显示提示。
- [ ] 正门双开/双关。
- [ ] 服务门锁定提示。
- [ ] 柜门/抽屉可开/关。
- [ ] 时钟 API 可调。
- [ ] `E` 与单击都可触发。
- [ ] 拖动后不误触单击。
- [ ] 提示不遮挡主要视线。

## 7. 视觉

### 7.1 影子方向

- [ ] 所有投影主光方向垂直向下。
- [ ] 高物体影子在脚下，不向侧面偏。
- [ ] 餐厅聚光灯不投第二套阴影。
- [ ] 宿舍只有吊灯主光；无 windowSpill/侧向 fill。
- [ ] 动态门/抽屉不触发阴影重烘焙。

### 7.2 结构

- [ ] 无门后套门。
- [ ] 无漂浮叶片/花头/餐具。
- [ ] 无穿模、接缝、黑洞。
- [ ] 画像/时钟/扬声器/绿植不重叠。
- [ ] 家具落地，不悬空。

## 8. 性能

在 1920×1080、硬件渲染、非全屏下测：

| 指标 | 目标 | 实测 |
|---|---|---|
| FPS | ≥30 底线，目标约 60 | ____ |
| draw calls | ≤90 | ____ |
| 三角面 | ≤450k | ____ |
| 纹理 | ≤16MB，单图 ≤1024² | ____ |
| 首屏 | 尽快，无长时间白屏 | ____ |
| console | 0 error | ____ |
| 网络 | 无外部请求 | ____ |

- [ ] FPS 稳定，不是瞬时峰值。
- [ ] 低帧率时自适应 pixelRatio 生效。
- [ ] 场景稳定后无每帧 geometry 创建。
- [ ] 阴影只烘焙一次（静态后）。

3. 餐桌/五件套近景。
4. 餐具柜开门/抽屉。

7. 天鹅时钟。
8. 绿植枝叶连接。

截图要求：

- 分辨率一致（如 1600×900）。
- 无 HUD 的场景图与带 HUD 的集成图分开。
- 不裁掉关键结构（门、桌角、阴影）。
- 文件保存到 `preview/`，并在 README 中引用。

## 12. 失败处理

- **先复现**：记录 URL、输入、相机位置、console。
- **缩小范围**：单场景、单交互、单碰撞体。
- **不要用“看起来还行”替代测试**。
- 修复后重跑同一条测试，并补一条回归测试。
- 性能回退时先看 draw calls/三角面/阴影/纹理，不要盲目降画质。
