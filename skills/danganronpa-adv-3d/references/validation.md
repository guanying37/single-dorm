# 场景与资产验收

验收对象：**简报完整、资产可复用、空间成立、固定机位与移动机位分别成立、光影一致、性能达标、能接入**。

固定机位和移动机位是两套 gate；同场景两者都要时，两套都跑。

## 1. 简报 gate

- [ ] `sceneId`、名称、地点类型、剧情功能明确。
- [ ] 尺寸、层高、门洞、连接房间明确。
- [ ] 明确要 **固定 / 移动 / 两者都要**。
- [ ] 固定机位：3–5 个 shot（position/target/fov/用途）。
- [ ] 移动机位：start/眼高/玩家半径/动线/碰撞。
- [ ] 交互物有 id/类型/行为。
- [ ] 资产分 reuse/new/oneoff，新增有理由。
- [ ] 灯光配方明确，阴影方向明确。
- [ ] 固定/移动预算分别明确。
- [ ] 禁忌（人物/文字/剧情）明确。

## 2. 资产 gate

- [ ] 每件新资产有真实尺寸、pivot、材质槽、碰撞。
- [ ] 家具族/道具族命名符合规范。
- [ ] 至少一个复用场景；oneoff 有说明。
- [ ] 桌面小物无碰撞、无文字。
- [ ] 植物有枝干/叶柄，不漂浮。
- [ ] 墙面道具不重叠、不穿门洞/窗/灯。
- [ ] 资产清单完整（reuse/new/oneoff）。

## 3. 空间 gate

### 共用

- [ ] 墙/地/顶无缝隙、漏面、黑洞。
- [ ] 门窗/线脚接缝自然。
- [ ] 从每个固定 shot 看，无穿帮/穿模。
- [ ] 移动可达区域从任何角度无黑洞。

### 仅移动机位

- [ ] 房间能从门口走进去，不穿墙。
- [ ] 门洞净宽 ≥0.70 m（玩家半径 0.30 m）。
- [ ] 桌椅/柜体不挡主通道。
- [ ] 桌下不可穿；桌角可走近。
- [ ] 楼梯/高差有真实坡道/台阶，不靠隐形墙。

## 4. 固定机位 gate

- [ ] 3–5 个 shot，构图有差异。
- [ ] 每个 shot 有 position/target/fov/用途。
- [ ] 机位不穿墙/家具，y 在 1.4–1.8 m。
- [ ] 前景/中景/背景成立。
- [ ] 镜头外不可见区域可以不存在，但不能被看到。
- [ ] 镜头切换不闪白、不重置场景。
- [ ] 镜头不是第二套模型。
- [ ] 不要求 collision/完整可达空间。

## 5. 移动机位 gate

- [ ] 有 start，且不在家具/墙里。
- [ ] 眼高 1.80 m；俯仰 ±83°；无翻转。
- [ ] 走路/跑步晃动正确；停止归位。
- [ ] 全屏指针锁定/非全屏拖动/右键固定/中键回正。
- [ ] 所有可达区域有碰撞；门/柜/抽屉动态同步。
- [ ] 快速跑动不穿模；墙角/桌角不卡死。
- [ ] 所有可达区域灯光成立，无死黑。
- [ ] 如果同场景也有固定机位，移动模式仍独立成立。

## 6. 光影 gate

- [ ] 只有一个投影主光。
- [ ] 顶灯室内主光垂直向下。
- [ ] 窗光/日光不投影。
- [ ] 高物体影子在脚下，不侧偏。
- [ ] 动态门/抽屉不投影。
- [ ] 无 Bloom/SSAO；无纯黑阴影/过曝白墙。

## 7. 性能 gate

- [ ] 固定机位 ≤250k 三角面 / ≤60 draw calls。
- [ ] 移动机位 ≤450k / ≤90。
- [ ] 纹理 ≤16 MB；单图 ≤1024²。
- [ ] 静态几何合批；无每帧 geometry。
- [ ] 阴影只烘焙一次。
- [ ] console 无 error；无 404；无外部请求。
- [ ] 同场景两者都要时，按移动预算验收，固定 shot 单独检查构图。

## 8. 接入 gate

- [ ] 注册表有 `sceneId`、标题、加载器、`modes`。
- [ ] `cameraModes.fixed` 与 `moving` 独立配置。
- [ ] 同页切换只渲染 active。
- [ ] 切换保存/恢复视角、清按键、重置 frozen。
- [ ] 本地服务器可启动；`file://` 有提示。
- [ ] 独立预览页可用，但不是唯一入口。

## 9. 截图

固定机位：

- [ ] 每个 shot 一张。
- [ ] 至少一张带 HUD/场景切换。
- [ ] 构图/前景/中景/背景可读。

移动机位：

- [ ] 入口视角。
- [ ] 主要动线/可达区域。
- [ ] 近景（家具/道具/材质）。
- [ ] 碰撞/通道验证（可选俯视）。
- [ ] 灯光/阴影验证。

两者都要：两套截图都交。

## 10. 交接给建模提示词阶段

交接包：

- `scene-brief.md`；
- `scene-spec.yaml`（含 fixed/moving 两段）；
- `asset-list.md`；
- kit 模块清单；
- 固定 shot 列表；
- 移动 start/动线/碰撞要求；
- 材质/灯光配方；
- 固定/移动预算；
- 参考图/色板；
- 未完成项。

要求：下一阶段不需要再问“多大、门在哪、固定镜头看哪、玩家从哪走、用什么灯”。
