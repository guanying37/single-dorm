# 性能预算与优化

目标：新场景在 1080p 接近 60 FPS，同时保留碰撞、相机锚点和光影方向。

## 1. 预算

| 场景类型 | 三角面 | draw calls | 纹理 | 阴影 |
|---|---:|---:|---:|---|
| 移动机位（教室/走廊/体育馆） | ≤450k | ≤90 | ≤16 MB | 1 张 2048² |
| 固定机位（小房间/过场） | ≤250k | ≤60 | ≤16 MB | 1 张 1024–2048² |
| 移动大空间（体育馆） | ≤450k | ≤100 | ≤16 MB | 1 张 2048² |

- 单图 ≤1024²。
- 1080p 目标约 60 FPS；底线 30 FPS。
- 阴影只烘焙一次；动态门/抽屉不投影。
- 无 Bloom/SSAO/后处理。

## 2. 合批

- 静态几何按材质合并；一个材质一个 mesh。
- 椅子、桌子、书、纸、餐具、叶片、线脚都进静态批次。
- 一个场景的材质数量控制在 15–25 个；超过要合并材质族。
- 相同材质不同纹理（如多幅画）用图集/贴图数组，不要每个一幅材质。
- 动态对象（门、抽屉、钟摆、指针）单独 mesh，不进静态批次。

## 3. 纹理

- 程序化 Canvas 纹理优先；单张 ≤1024²。
- 地面/墙面用米制 UV，避免拉伸。
- 同类材质共享纹理：木、金属、布、石。
- 多张小图合并图集；不要把 20 张 512² 分别绑定。
- 需要透明时控制 overdraw；玻璃/窗帘不要大面积叠层。

## 4. 几何

- 家具用低模 + 法线/材质表现细节；不要每个抽屉 500 面。
- 桌面小物可合并；远距离小物用贴图/简化几何。
- 重复资产（书架、桌椅）用同一 geometry + 矩阵实例/合并。
- 大空间按区域分批；不要一个 50 万面 mesh 全场景。
- 需要 LOD 时：近景完整、中景简化、远景/机位外合并。

## 5. 灯光/阴影

- 一盏投影主光；其他灯 `castShadow=false`。
- 阴影相机紧贴场景，避免过大范围导致低分辨率。
- 动态门/抽屉不 castShadow。
- 静态场景渲染一帧后关闭 shadow 自动更新。
- 点光/聚光数量控制在 8–12 盏；更多用 emissive/环境光近似。

## 6. 固定机位 vs 移动机位

- **固定机位**：只优化镜头可见区域；镜头外可 LOD/省略；不需要为不可达区域做碰撞或完整天花。
- **移动机位**：覆盖玩家所有可达区域；不能只优化一个机位；碰撞/门洞/背面都要完整。
- 同一场景两者都要：模型只建一份；性能按移动预算执行，固定 shot 可额外提高局部精度。
- 不要为了固定机位构图删掉移动模式的碰撞体。
- 不要用移动模式的完整空间要求，强迫纯固定场景补全镜头外区域。

## 7. 测量

每个场景记录：

```yaml
fps: 60
drawCalls: 68
triangles: 352000
textures: 14
geometries: 90
resolution: 1920x1080
device: "GTX 1060 / 集成显卡"
```

要求：

- 稳定 5 秒以上再读数。
- 区分“进入场景瞬间”和“稳定态”。
- 同时记录 console error / 404。
- 低帧率时先查 draw calls、阴影、纹理、透明 overdraw，不要盲目降画质。

## 8. 超标处理

| 问题 | 优先处理 |
|---|---|
| draw calls 高 | 合材质、合并静态、图集 |
| 三角面高 | 简化家具、LOD、合并小物 |
| 纹理大 | 降分辨率、图集、共享材质 |
| 阴影卡 | 关小灯 shadow、缩小 shadow camera、静态烘焙 |
| 透明 overdraw | 减少玻璃层、缩窗帘、用不透明近似 |
| 首屏慢 | 懒加载场景、压缩纹理、减少材质编译 |

## 9. 不能牺牲

- 移动模式的碰撞；
- 固定机位的镜头构图；
- 主光方向；
- 交互；
- 门/抽屉动态碰撞；
- 资产可读性（不能为了省面把桌子做成纸片）。

## 10. 验收

- [ ] 1080p 稳定接近 60 FPS。
- [ ] 移动机位 ≤450k / ≤90；固定机位 ≤250k / ≤60。
- [ ] 纹理 ≤16 MB，单图 ≤1024²。
- [ ] 一个投影主光；阴影只烘焙一次。
- [ ] 场景稳定后无每帧 geometry 创建。
- [ ] 无 console error / 404。
- [ ] 低端设备有 pixelRatio 自适应。
- [ ] 同场景两者都要时，按移动预算验收，固定 shot 单独检查构图。
