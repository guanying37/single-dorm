# 家具与道具族

目标：用有限的家具族和道具族覆盖多个场景，而不是每间房从零设计。

## 1. 家具族

| 族 | id 前缀 | 常见场景 |
|---|---|---|
| 学生桌 | `prop.desk.student` | 教室、图书室 |
| 餐桌 | `prop.table.dining` | 餐厅、食堂 |
| 椅子 | `prop.chair.*` | 教室、餐厅、图书室 |
| 讲台/教师桌 | `prop.lectern` | 教室 |
| 储物柜 | `prop.locker` | 教室、走廊、更衣室 |
| 书架 | `prop.shelf.book` | 图书室、宿舍 |
| 床 | `prop.bed.single` | 宿舍、医务室 |
| 柜/抽屉 | `prop.cabinet.*` | 餐厅、教室、宿舍 |
| 实验室台 | `prop.bench.lab` | 实验室 |
| 体育器材 | `prop.gym.*` | 体育馆 |
| 卫浴 | `prop.bath.*` | 浴室/更衣室 |
| 服务台 | `prop.counter` | 食堂、接待 |

### 每件家具必须定义

```yaml
id: prop.desk.student
dimensions: [0.65, 0.72, 0.45]
pivot: bottom-center
forward: +Z
materials: [wood.oak, metal.dark, laminate.top]
collider: obb
variants: [plain, drawer, graffiti-free]
reuse: [classroom, library]
```

- 尺寸为 **宽 × 高 × 深**（m）。
- 桌面/座面高度写清。
- 抽屉/门要有开合方向与行程。
- 变体只改材质/小结构，不另起一套。

## 3. 道具族

| 族 | 例子 | 碰撞 |
|---|---|---|
| 桌面小物 | 书、纸、笔、杯、餐具 | 无 |
| 墙面 | 钟、画框、布告板、监控、扬声器 | 无 |
| 灯具 | 吸顶灯、吊灯、台灯、壁灯 | 无 |
| 储物 | 箱、篮、文件夹 | 可选 |
| 器材 | 球、器械、垫子 | 可选 |
| 植物 | 盆栽、枝叶 | 盆可碰撞 |
| 布艺 | 桌布、窗帘、坐垫 | 无 |

规则：

- 小道具不单独建材质；用道具族共享材质。
- 书本/纸张不能有可读文字；用空白/抽象纹理。
- 植物必须有枝干/叶柄连接，不能漂浮。
- 墙面道具不能互相重叠；与门洞、窗、灯保持间距。
- 监控/扬声器要贴墙/贴顶，不能悬空。

## 4. 命名

```text
prop.<类>.<子类>.<变体>
prop.desk.student.plain
prop.chair.student.wood
prop.locker.tall.double
prop.clock.wall.roman
prop.monitor.dome
prop.speaker.wall
mat.<族>.<变体>
mat.wood.oak
mat.metal.brass
```

## 5. 材质槽

每件家具最多 3–4 个材质槽：

- 结构木/金属；
- 台面/软包；
- 把手/脚垫；
- 可选发光体。

不要一件家具 8 个材质；会增加 draw calls 和资产维护成本。

## 6. 碰撞

- 家具：OBB，按外轮廓；不要用一个房间大的盒子。
- 椅子：独立碰撞，不要并进桌子。
- 桌下空间：玩家不能穿过桌面；但桌角可走近。
- 柜门/抽屉：动态碰撞。
- 小道具：默认无碰撞；剧情需要可加小 circle。
- 家具底部贴地；不要用碰撞体补偿悬空。

## 7. 变体策略

优先：

1. 同模型换材质（木色、布色、金属）。
2. 同模型换小配件（把手、脚垫、抽屉面板）。
3. 同模型换尺寸档位（单/双、长/短）。

不优先：

- 每间房重新雕一把椅子。
- 每个场景一套独特桌子。
- 用微小造型差异制造“新资产”。

## 8. 资产清单

每个场景输出：

```text
id | 类型 | 尺寸 | 材质槽 | 碰撞 | 变体 | 复用场景 | 备注
```

并标记：

- `reuse`：来自现有库；
- `new`：新增；
- `oneoff`：剧情专用，需说明理由。

## 9. 首批资产缺口

教室：

- 学生课桌/椅（可复用餐厅椅改款）
- 讲台
- 空白黑板
- 储物柜
- 布告板（无文字）
- 窗帘

走廊：

- 门（单/双）
- 储物柜
- 导向牌（无文字，图形化）
- 长椅
- 线性灯

体育馆：

- 看台/长椅
- 球架/器材架
- 地垫/标线（无文字）
- 高棚灯
- 记分牌（不显示真实文字，可空白）

## 10. 自检

- [ ] 每件家具有尺寸、pivot、材质槽、碰撞。
- [ ] 每件家具至少有一个复用场景。
- [ ] 小道具没有可读文字。
- [ ] 植物有枝干/叶柄。
- [ ] 椅子独立碰撞，桌子不用整块大盒。
- [ ] 资产清单区分 reuse/new/oneoff。
