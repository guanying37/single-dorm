# 移动机位（第一人称 / 探索）

移动机位是**玩家可达空间**。房间必须完整、可走、可碰撞，不能只为一张画面服务。

## 1. 适用

- 自由探索、走廊、宿舍、餐厅、体育馆、庭院。
- 玩家需要走到桌前、打开柜门、靠近门/窗。
- 需要 360° 观察，或至少能绕行主要家具。
- ADV 对话可以叠加固定机位，但移动模式本身要独立成立。

不适用：纯过场/审判/回忆，只要固定镜头。那种用 `camera-fixed.md`。

## 2. 核心原则

1. **空间完整**：玩家可达区域必须有墙/地/顶，不能从任何可达角度看到黑洞。
2. **碰撞可信**：墙、桌、椅、门、柜、抽屉都要挡人；不能穿模、卡死。
3. **眼高稳定**：基准 1.80 m；走路/跑步只做有限起伏。
4. **动线成立**：门洞、桌间、柜前、窗边都要能到达。
5. **不复制模型**：固定机位和移动机位共用同一场景；相机预设不是第二套几何。

## 3. 玩家参数

| 项 | 默认 |
|---|---|
| 眼高 | 1.80 m |
| 玩家半径 | 0.30 m |
| 步行 | 2.6 m/s |
| 跑步 | 6.2 m/s |
| 加速度 | 14 |
| 俯仰限制 | ±83° |
| 中键回正 | 0.6 s |
| 走路起伏 | ±1.4 cm |
| 跑步起伏 | ±2.8 cm |
| 子步进 | ≤0.075 m |
| 碰撞迭代 | 3 pass |

## 4. 移动规格

```yaml
moving:
  enabled: true
  start:
    x: 0
    z: 5.2
    yaw: 0
    pitch: 0
  eyeHeight: 1.8
  playerRadius: 0.30
  speed:
    walk: 2.6
    run: 6.2
  bob:
    walk: 0.014
    run: 0.028
    lateral: true
    roll: true
  collision: true
  doors:
    - id: door.main
      dynamic: true
  interactions:
    - door.main
    - locker.1
```

- `start` 不能在家具/墙里。
- 门洞净宽 ≥0.70 m；建议 ≥0.90 m。
- 桌角可走近，椅子独立碰撞。
- 桌下不能穿过；柜门/抽屉动态碰撞。
- 楼梯/台阶必须有真实高差/坡道，不用隐形墙。

## 5. 空间要求

- 玩家可达的所有方向都要有完整墙面/天花板/地面。
- 入口/出口不能看到未建模区域。
- 家具不能把主通道堵死；至少保留 0.70 m 净宽。
- 窗边/柜前/门口要留站位。
- 镜子/玻璃背后要有内容，不能黑洞。
- 场景边界用墙/门/雾/遮挡收口。

## 6. 相机

- 第一人称，FOV 60–75（默认 68）。
- 眼高 1.80 m；视点起伏不改变碰撞高度。
- 俯仰 ±83°，yaw 360°。
- 全屏指针锁定；非全屏左键拖动；右键固定；中键回正。
- 跑步晃动明显强于走路；停止后归位。
- 不侧翻、不倒置、不穿墙。

## 7. 灯光

- 顶灯室内主光垂直向下；窗光/日光作非投影填充。
- 玩家能看到的所有面都要受光；不能有死黑房间。
- 动态门/抽屉不投影；阴影只烘焙一次。
- 低照度场景用环境光/发光体补，不要加侧向 key。

## 8. 性能

| 项 | 目标 |
|---|---|
| 三角面 | ≤450k |
| draw calls | ≤90 |
| 纹理 | ≤16 MB |
| 阴影 | 1 张 2048² |
| 目标 | 1080p 约 60 FPS |

- 所有可达区域都要优化，不能只优化一个机位。
- 重复家具/书架合批；桌椅独立碰撞。
- 大空间按区域分批；必要时 LOD。

## 9. 验收

- [ ] 每个可达方向无黑洞/漏面。
- [ ] 墙/桌/椅/门/柜/抽屉碰撞正确。
- [ ] 门洞 ≥0.70 m；主通道不堵。
- [ ] 桌角可走近，椅子仍阻挡。
- [ ] 快速跑动不穿模；墙角/桌角不卡死。
- [ ] 眼高 1.80 m；俯仰限制；无翻转。
- [ ] 走路/跑步晃动正确；停止归位。
- [ ] 开门/拉抽屉碰撞同步。
- [ ] 所有可达区域灯光成立，无死黑。
- [ ] 如果同场景也有固定机位，另按 `camera-fixed.md` 验收机位构图。

## 10. 不要做

- 不要用固定机位标准验收移动场景。
- 不要只建镜头可见的面，然后让玩家看到背面黑洞。
- 不要用隐形墙代替门/栏杆/边界。
- 不要用一块大盒子包住桌子和椅子。
- 不要让玩家从桌下穿过。
- 不要为了“省面”删掉可达区域的墙/地/顶。
- 不要用侧向补光解决暗部，破坏影子方向。
