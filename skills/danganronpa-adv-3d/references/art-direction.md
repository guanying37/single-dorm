# 美术方向

本文件是建模提示词的风格基准。目标不是复刻某一间餐厅，而是让所有新场景看起来属于同一款《弹丸论破》风格 ADV 游戏。

## 1. 核心风格

> **干净的日式校园空间 + 自然材质 + 少量高饱和图形色 + 略夸张的轮廓与灯具。**

不是照片写实，也不是全低多边形动画风。取中间：

- 空间结构可信；
- 材质自然、不过度脏旧；
- 轮廓比现实略干净、略图形化；
- 关键道具/灯具/门框可以更夸张；
- 颜色有记忆点，但不整体滤镜化。

## 2. 视觉支柱

### 2.1 希望峰学园

- 校园空间带一点“精英学校”的秩序感：对称、线脚、干净墙裙、成排家具。
- 但不要奢华酒店：不铺大理石宫殿、不堆金饰。
- 允许局部破败、封窗、旧木板、监控、铁门，形成“正常校园下的异常”。

### 2.2 ADV 构图

- 房间要经得起固定机位：门口、讲台、窗边、走廊纵深。
- 前景/中景/背景分层；不要所有家具贴墙。
- 灯具、门框、窗可以成为画面框架。

### 2.3 图形化点缀

- 弹丸论破红/洋红：用于重点门、椅子、地毯、标记。
- 青绿/墨绿：用于黑板、柜体、植物。
- 金色/黄铜：用于钟、灯具、把手。
- 高饱和色只占画面 5–10%，不要整体高饱和。

## 3. 色板

### 基础色

| 名称 | Hex | 用途 |
|---|---|---|
| 暖白 | `#efe8dc` | 墙面、天花 |
| 象牙 | `#e4d8c4` | 石材、纸张 |
| 浅橡木 | `#c49a6c` | 桌椅、门 |
| 深胡桃 | `#6b4a32` | 收边、旧家具 |
| 鼠尾草 | `#8b966c` | 布艺、植物 |
| 陶土 | `#a8664a` | 花盆、砖 |
| 暖灰 | `#8f877b` | 金属、石材阴影 |
| 炭黑 | `#252321` | 灯架、监控、铁件 |

### 点缀色

| 名称 | Hex | 用途 |
|---|---|---|
| 弹丸红 | `#9e2b33` | 门、地毯、重点家具 |
| 洋红 | `#b23a5e` | 小面积标记/布艺 |
| 青绿 | `#2f5d57` | 黑板、柜体 |
| 黄铜 | `#b08a4f` | 钟、把手、灯具 |
| 冷青 | `#7f9a9a` | 玻璃、湿区 |
| 警示黄 | `#c9a24a` | 小面积标识/器材 |

使用规则：

- 60% 基础中性色，30% 木/布/石，10% 点缀。
- 一个房间最多 2 个高饱和点缀色。
- 不要把红/洋红铺满整面墙。

## 4. 材质族

| 族 | 特征 | 常见位置 |
|---|---|---|
| 灰泥 | 暖白、轻微 bump、低光泽 | 墙、天花 |
| 木 | 浅橡木/胡桃、直纹、中等粗糙 | 桌、椅、门、柜 |
| 石材 | 暖灰/米色、低反射、900 砖缝 | 地面、台面 |
| 瓷砖 | 小规格、湿区、冷青/白 | 浴室、厨房 |
| 金属 | 黄铜/钢/铁、粗糙度中 | 灯具、把手、监控 |
| 布 | 亚麻/棉、方格/纯色 | 桌布、窗帘、坐垫 |
| 玻璃 | 低粗糙、轻微色偏 | 窗、柜门、灯罩 |
| 纸/木浆 | 哑光、轻微纤维 | 书、纸、海报底 |
| 橡胶/塑料 | 哑光、深色 | 器材、线缆、脚垫 |
| 发光体 | 暖白/冷白 emissive | 灯罩、LED、屏幕 |

### 材质规则

- 每件资产最多 3–4 个材质槽；不要一件家具 8 个材质。
- 木纹方向要统一；桌面横向、桌腿纵向。
- 地面纹理按米制 UV，不拉伸。
- 玻璃不要全透明；轻微反射/色偏更可信。
- 发光体不要纯白过曝；用暖白/冷白分层。

## 5. 造型与比例

- 墙厚 0.18–0.26 m；门高 2.2 m；眼高 1.8 m。
- 课桌约 0.65 × 0.45 × 0.72 m；椅座高 0.42–0.45 m。
- 餐桌 1.8 × 1.0 × 0.75 m；餐椅座高 0.45 m。
- 床 1.2 × 2.0 m；床头高 0.9–1.1 m。
- 窗台高 0.9 m；窗顶 2.1–2.4 m（按层高）。
- 家具轮廓比现实略干净：少一点圆角噪点，多一点明确平面。
- 重要道具可以放大 5–10%，形成图形记忆点。

## 6. 磨损与异常

- 只做局部磨损：门把手、桌角、地面入口、椅背。
- 不整体做脏、不做大面积锈迹。
- 异常元素（封窗木板、监控、铁门、警示带）要克制，像“学校里发生了事”，不是废土。
- 不使用真实文字/字体贴图；告示板、黑板保持空白或抽象图形。

## 7. 灯光氛围

- 教室：中性白日光灯 + 窗光；干净、略冷。
- 走廊：线性灯 + 端景暖光；纵深。
- 体育馆：高棚灯 + 天窗；大空间、顶部亮。
- 图书室：暖白台灯 + 低照度环境；安静。
- 裁判场：聚光 + 暗环境；高对比。
- 浴室：冷白 + 湿区反射；干净。
- 庭院：日光 + 阴影；室外。

阴影方向：

- 顶灯室内默认主光垂直向下。
- 窗光/日光只做非投影填充，不能产生侧向影子。
- 裁判场可用垂直聚光，但仍然是“主光方向一致”，不要侧向 key。

## 8. 不要做

- 不要照片级写实皮肤、人物或面部。
- 不要全低多边形/卡通渲染，除非用户明确要求。
- 不要赛博朋克霓虹、废土、恐怖游戏式脏污。
- 不要用真实品牌、真实校徽、真实文字。
- 不要自绘二次元插画/海报。
- 不要用高饱和色铺满整个房间。
- 不要让所有房间都变成同一种餐厅色调；每个地点要有自己的主色与灯光，但共享材质族。

## 9. 风格自检

- [ ] 一眼能看出是日式校园，而不是酒店/办公室/住宅。
- [ ] 基础色占主导，点缀色不超过 10%。
- [ ] 材质自然，没有塑料感/纯黑阴影。
- [ ] 轮廓干净但不过度卡通。
- [ ] 异常元素克制，不抢主体。
- [ ] 固定机位构图有前景/中景/背景。
- [ ] 灯光方向一致，没有侧向影子。
