# 生产线计划

本文件定义「为这款 ADV 游戏继续做建模」的批次、优先级与交付物。当前阶段只做 skill / 简报 / 资产规划，不生成实际几何。

## 1. 目标

把一次性的场景制作，变成可重复的生产线：

```text
游戏资料 → 场景简报 → 空间程序 → kit 选型 → 家具/道具 → 材质/灯光
→ 场景类/相机锚点 → 优化 → 注册接入 → 验收 → 建模提示词/几何
```

重点是**复用**：新房间优先由已有 kit 拼装，只有确实缺的模块才新增。

## 2. 已确定的方向

| 项 | 决定 |
|---|---|
| 首批 | 教室 → 走廊/玄关 → 体育馆 |
| 场景形态 | 同一模型，可走 + 固定 ADV 机位 |
| 资产粒度 | 模块化套件 + 家具/道具库优先 |
| 运行时 | Three.js 网页优先；米制/PBR/glTF 友好 |
| 风格 | 自然写实骨架 + 弹丸论破式图形点缀 |
| 当前餐厅/宿舍 | examples，不是硬规则 |

## 3. 批次

### 批次 1：校园日常核心

| 顺序 | 场景 | 目的 | 复用 |
|---|---|---|---|
| 1 | **教室** | 验证课桌椅阵列、窗、黑板、储物柜、吊灯/日光、ADV 机位 | 墙/地/顶/门/窗/桌椅/灯具 |
| 2 | **走廊/玄关** | 连接教室、餐厅、宿舍；验证门洞、转角、导向 | 墙/地/门/线脚/灯具 |
| 3 | **体育馆** | 大空间、高天花、看台、器材；压力测试 | 墙/顶/门/灯具/器材族 |

### 批次 2：信息与审判空间

| 顺序 | 场景 | 目的 |
|---|---|---|
| 4 | **图书室** | 书架阵列、阅读桌、安静氛围 |
| 5 | **裁判场** | 圆形/多边形构图、聚光、强烈视觉记忆点 |

### 批次 3：生活与外部空间

| 顺序 | 场景 | 目的 |
|---|---|---|
| 6 | **浴室/更衣室** | 瓷砖、湿区、储物柜、雾面材质 |
| 7 | **庭院** | 室外/半室外；日光、植物、围墙、地面拼接 |
| 8 | **其他宿舍变体** | 复用宿舍壳，换配色/家具/剧情道具 |

## 4. 为什么这个顺序

- **教室**：高频、可复用资产多、规模可控，适合做第一条完整生产线。
- **走廊**：把独立房间变成可连通的校园；门/转角/导向模块是后续所有场景的基础。
- **体育馆**：检验大空间、长跨度、高天花和器材，和教室形成尺度对比。
- **图书室**：重复书架/桌椅，适合验证批处理与实例化。
- **裁判场**：视觉标志性强，但圆形构图、聚光和角色站位复杂，放在 kit 稳定之后。
- **浴室/庭院**：材质/室外系统特殊，放在最后。

## 5. 每个场景的阶段

| 阶段 | 产出 | 完成标准 |
|---|---|---|
| B0 资料 | 游戏设定、剧情功能、已有资产 | 知道场景为什么存在 |
| B1 简报 | `scene-brief.md` 填完 | 尺寸、门、机位、资产、灯光明确 |
| B2 灰盒 | 空间程序 + blockout | 门洞、动线、相机成立 |
| B3 kit | 复用模块清单 + 新增模块 | 接缝、门洞、转角能拼 |
| B4 家具/道具 | 资产清单 + 选型 | 尺寸、pivot、collider、材质槽明确 |
| B5 材质/灯光 | 材质族 + 灯光配方 | 风格统一；影子方向正确 |
| B6 场景类 | 相机锚点、交互、碰撞 | 可走/ADV 模式都能用 |
| B7 优化 | 合批、纹理、LOD | 达到预算 |
| B8 接入 | 注册表、入口、预览 | 不刷新切换；无 404 |
| B9 验收 | 截图、性能、资产清单 | 所有 gate 通过 |

## 6. 资产复用优先级

1. **房间壳**：墙、地、顶、门、窗、线脚。
2. **家具族**：桌、椅、柜、床、架、讲台、器材。
3. **道具族**：书、纸、杯子、餐具、灯具、监控、扬声器。
4. **场景专用 one-off**：只有剧情特写需要，单独标记。

新增模块的门槛：

- 至少能在两个场景复用；或
- 是当前场景不可替代的结构件；或
- 是剧情特写道具。

否则先不做。

## 7. 场景复杂度估算

| 场景 | 规模 | 主要风险 | 优先级 |
|---|---|---|---|
| 教室 | 中 | 桌椅数量、窗光、黑板 | P0 |
| 走廊 | 小–中 | 门洞/转角/导向 | P1 |
| 体育馆 | 大 | 高天花、看台、器材、阴影 | P1 |
| 图书室 | 中 | 书架重复、通道 | P2 |
| 裁判场 | 中–大 | 圆形构图、聚光、站位 | P2 |
| 浴室 | 中 | 瓷砖、湿区、雾面 | P3 |
| 庭院 | 大 | 室外光、植物、地面拼接 | P3 |

## 8. 性能预算

| 类型 | 三角面 | draw calls | 目标 |
|---|---:|---:|---|
| 可走场景 | ≤450k | ≤90 | 1080p 约 60 FPS |
| 纯固定机位 | ≤250k | ≤60 | 可提高道具精度 |

- 纹理 ≤16 MB，单图 ≤1024²。
- 一张静态阴影；动态门/抽屉不投影。
- 无 Bloom/SSAO。
- 场景稳定后不再新增 geometry。

## 9. 成功指标

- 新场景能在 **1 份简报 + 1 套 kit + 1 个场景类** 内完成。
- 复用率 ≥60%（按资产数量计）。
- 不出现“每间房都从零建墙/桌椅”。
- 新场景可直接注册进现有同页切换。
- 1080p 达到预算，无 console error。
- 交接给建模提示词阶段时，不需要再猜空间、镜头、资产、灯光。

## 10. 当前阶段不做什么

- 不生成教室/走廊/体育馆的几何。
- 不写最终建模提示词。
- 不改现有餐厅/宿舍模型。
- 不新增贴图/参考画。
- 不安装额外依赖。

先把 skill、简报模板、kit 目录、资产清单和验收 gate 定稳。
